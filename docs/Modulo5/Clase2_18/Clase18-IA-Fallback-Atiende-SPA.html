Qué cambia respecto a la Clase 17

Antes la IA ayudaba a construir Atiende. Desde hoy la IA vive dentro del producto y el equipo responde por su costo, sus fallas y la calidad de sus respuestas.

Comprender · costo

Una petición HTTP se cobra por tokens de entrada y salida

El mensaje, las instrucciones y el formato consumen entrada. La respuesta y el razonamiento consumen salida.

Definición técnica

Token

Unidad en la que cada modelo divide el texto antes de procesarlo. Puede ser una palabra, un fragmento, un signo o parte de un emoji.

Mediciones de la guía con qwen3:1.7b
Modelo mental

Son fichas de un juego: el cobro depende de cuántas fichas necesita la petición, no del número visible de palabras.

Predice

¿Una palabra siempre equivale a un token?

Comprobar

No. El tokenizador y el “sobre” fijo de la conversación cambian el conteo.

# SPEC · Atiende · Fase 2: la IA entra al producto

## Problema
El equipo de soporte no sabe qué clientes están molestos hasta leer cada mensaje.
Antes de automatizar más (Fase 3), necesitamos que Atiende pueda hablar con un modelo de IA de forma confiable, segura y con costo conocido.

## Objetivo de la fase 2
Detectar el sentimiento de un ticket (MOLESTO, NEUTRAL, CONTENTO) usando IA, con respaldo automático si el proveedor principal falla.

## Fuera de alcance (llega después)
- Guardar el sentimiento en la base de datos.
- Clasificación por categoría, prioridad automática, borradores de respuesta y chatbot.
- Autenticación (deuda técnica declarada: este endpoint consume créditos).

## Proveedores
| Orden | Nombre | Formato de API | Servicio en clase | Servicio en producción |
|---|---|---|---|---|
| 1 | openai | Chat Completions (OpenAI) | Gemini, plan gratuito | OpenAI |
| 2 | claude | Messages (Anthropic) | Ollama local | Claude |

## Reglas
1. Si un proveedor falla, se intenta el siguiente. Si todos fallan: 503.
2. Errores HTTP 400, 401, 403 y 404 son de configuración: se registran como ERROR. Los demás (429, 5xx, sin conexión, tiempo agotado, respuesta vacía) son temporales: WARN.
3. La respuesta del modelo se valida: si no es uno de los tres sentimientos, se responde 502.
4. Las llaves viven solo en `secrets.properties` (raíz del proyecto), nunca en el código ni en Git.
5. Cada análisis informa proveedor, modelo, tokens de entrada y salida, costo estimado en USD y milisegundos.
6. En los logs nunca se escribe el mensaje del cliente ni una llave.
7. Límites: tiempo máximo de espera y tokens máximos de salida, configurables.

## Endpoint
| Método | Ruta | Respuestas |
|---|---|---|
| POST | /api/tickets/{id}/sentimiento | 200 análisis · 404 ticket no existe · 502 respuesta inválida de la IA · 503 IA no disponible |

## Criterios de aceptación
- [ ] Con Gemini configurado, el análisis del ticket de Laura devuelve MOLESTO y `proveedor: openai`.
- [ ] Con una llave inválida, el análisis sigue funcionando con `proveedor: claude` y el log muestra un ERROR.
- [ ] Con Ollama apagado y llave inválida, la respuesta es 503.
- [ ] Una respuesta del modelo fuera de los tres valores produce 502.
- [ ] `secrets.properties` no aparece en `git status`.

# Atiende · instrucciones para el agente

## Contexto
Backend de atención al cliente de Grano Alto Café.
Antes de cambiar reglas de negocio, lee `SPEC.md`: es la fuente de verdad.

## Stack
- Java 17, Spring Boot 4.1, Maven, MySQL.
- Configuración solo en `application.properties`. Nunca `application.yml` ni perfiles.

## Arquitectura
- Paquete base `com.devsenior.atiende`, organizado por dominio: `ticket/`, `compartido/`.
- Capas: Controller → Service → Repository. El Controller no tiene lógica de negocio.
- DTOs como `record` en `<dominio>/dto`. Nunca expongas entidades JPA en la API.
- Un mapper propio por dominio (`@Component`), sin librerías de mapeo.
- Inyección por constructor. Nunca `@Autowired` sobre atributos.
- Enums persistidos con `@Enumerated(EnumType.STRING)`.
- Errores con excepciones propias y un `@RestControllerAdvice` en `compartido/`.

## Código
- Clases, métodos y variables en español.
- Sin Lombok: getters y setters explícitos.
- Validación de entrada con Jakarta Validation en los DTO de request.

## Tests
- JUnit 5 + Mockito. Los tests del Service no levantan Spring.
- Nunca modifiques un test para que pase. Si un test falla, explícame si la causa está en el test o en el código y espera mi decisión.
- Un test rojo contra la SPEC es una pregunta de negocio: no la resuelvas tú.

## IA (desde la Fase 2)
- Todo proveedor de IA implementa la interfaz `ProveedorIA` en el paquete `ia/`.
- Las llamadas HTTP se hacen con `RestClient`. Sin SDKs de proveedores ni Spring AI.
- Nunca escribas llaves en el código ni en `application.properties`: van en `secrets.properties`, que no puedes leer.
- Antes de usar una URL, un header, un parámetro o un nombre de modelo de una API de IA, verifícalo en la documentación oficial actual. Tu conocimiento puede estar desactualizado.
- Nunca registres en logs el mensaje del cliente ni las llaves.

## Límites
- No agregues dependencias al `pom.xml` sin preguntarme.
- No modifiques `application.properties` salvo que te lo pida.
- Si algo de la SPEC es ambiguo, pregunta antes de suponer.

01

Spring registra la configuración

package com.devsenior.atiende.ia;

import java.math.BigDecimal;
import java.math.RoundingMode;
import org.springframework.boot.context.properties.ConfigurationProperties;

@ConfigurationProperties(prefix = "atiende.ia")
public record IaProperties(
        int timeoutSegundos,
        int maxTokens,
        Proveedor openai,
        Proveedor claude
) {

    public record Proveedor(
            String url,
            String modelo,
            String llave,
            BigDecimal precioEntradaMillon,
            BigDecimal precioSalidaMillon
    ) {

        private static final BigDecimal UN_MILLON = BigDecimal.valueOf(1_000_000);

        public BigDecimal calcularCosto(int tokensEntrada, int tokensSalida) {
            BigDecimal entrada = precioEntradaMillon.multiply(BigDecimal.valueOf(tokensEntrada));
            BigDecimal salida = precioSalidaMillon.multiply(BigDecimal.valueOf(tokensSalida));
            return entrada.add(salida).divide(UN_MILLON, 6, RoundingMode.HALF_UP);
        }
    }
}

package com.devsenior.atiende.ia;

import java.util.Set;

public class ProveedorIAException extends RuntimeException {

    private static final Set<Integer> ERRORES_DE_CONFIGURACION = Set.of(400, 401, 403, 404);

    private final boolean errorDeConfiguracion;

    public ProveedorIAException(String proveedor, String motivo, boolean errorDeConfiguracion) {
        super(proveedor + ": " + motivo);
        this.errorDeConfiguracion = errorDeConfiguracion;
    }

    public static ProveedorIAException desdeEstadoHttp(String proveedor, int estadoHttp) {
        boolean deConfiguracion = ERRORES_DE_CONFIGURACION.contains(estadoHttp);
        return new ProveedorIAException(proveedor, "respondió HTTP " + estadoHttp, deConfiguracion);
    }

    public boolean isErrorDeConfiguracion() {
        return errorDeConfiguracion;
    }
}

package com.devsenior.atiende.ia;

import java.net.http.HttpClient;
import java.time.Duration;
import org.springframework.http.client.ClientHttpRequestFactory;
import org.springframework.http.client.JdkClientHttpRequestFactory;

public final class FabricaHttp {

    private FabricaHttp() {
    }

    public static ClientHttpRequestFactory conTimeout(int segundos) {
        Duration limite = Duration.ofSeconds(segundos);
        HttpClient httpClient = HttpClient.newBuilder()
                .version(HttpClient.Version.HTTP_1_1)
                .connectTimeout(limite)
                .build();
        JdkClientHttpRequestFactory fabrica = new JdkClientHttpRequestFactory(httpClient);
        fabrica.setReadTimeout(limite);
        return fabrica;
    }
}

                maxTokens,
                0.0);

        OpenAiFormato.Respuesta respuesta = enviar(peticion);
        long milisegundos = System.currentTimeMillis() - inicio;

        String texto = extraerTexto(respuesta);
        int tokensEntrada = respuesta.usage() == null ? 0 : respuesta.usage().promptTokens();
        int tokensSalida = respuesta.usage() == null ? 0 : respuesta.usage().completionTokens();

        return new RespuestaIA(texto, nombre(), config.modelo(), tokensEntrada, tokensSalida,
                config.calcularCosto(tokensEntrada, tokensSalida), milisegundos);
    }

    private OpenAiFormato.Respuesta enviar(OpenAiFormato.Peticion peticion) {
        try {
            return restClient.post()
                    .uri("/chat/completions")
                    .body(peticion)
                    .retrieve()
                    .body(OpenAiFormato.Respuesta.class);
        } catch (RestClientResponseException ex) {
            throw ProveedorIAException.desdeEstadoHttp(nombre(), ex.getStatusCode().value());
        } catch (ResourceAccessException ex) {
            throw new ProveedorIAException(nombre(), "sin conexión o tiempo agotado", false);
        }
    }

    private String extraerTexto(OpenAiFormato.Respuesta respuesta) {
        if (respuesta == null || respuesta.choices() == null || respuesta.choices().isEmpty()) {
            throw new ProveedorIAException(nombre(), "respuesta sin opciones", false);
        }
        String texto = respuesta.choices().get(0).message().content();
        if (texto == null || texto.isBlank()) {
            throw new ProveedorIAException(nombre(), "respuesta vacía", false);
        }
        return texto.strip();
    }

package com.devsenior.atiende.ia;

import java.util.List;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

@Service
public class AsistenteIA {

    private static final Logger log = LoggerFactory.getLogger(AsistenteIA.class);

    private final List<ProveedorIA> proveedores;

    public AsistenteIA(List<ProveedorIA> proveedores) {
        this.proveedores = proveedores;
    }

    public RespuestaIA completar(String instrucciones, String mensaje) {
        for (ProveedorIA proveedor : proveedores) {
            try {
                RespuestaIA respuesta = proveedor.completar(instrucciones, mensaje);
                log.info("IA ok proveedor={} modelo={} tokens={}/{} costoUsd={} ms={}",
                        respuesta.proveedor(), respuesta.modelo(),
                        respuesta.tokensEntrada(), respuesta.tokensSalida(),
                        respuesta.costoEstimadoUsd(), respuesta.milisegundos());
                return respuesta;
            } catch (ProveedorIAException ex) {
                if (ex.isErrorDeConfiguracion()) {
                    log.error("IA falló por configuración, se intenta el siguiente. {}", ex.getMessage());
                } else {
                    log.warn("IA falló temporalmente, se intenta el siguiente. {}", ex.getMessage());
                }
            }
        }
        throw new IaNoDisponibleException();
    }
}

package com.devsenior.atiende.compartido;

import com.devsenior.atiende.ia.IaNoDisponibleException;
import com.devsenior.atiende.ia.RespuestaIAInvalidaException;
import com.devsenior.atiende.ticket.TransicionInvalidaException;
import java.time.LocalDateTime;
import java.util.stream.Collectors;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(RecursoNoEncontradoException.class)
    public ResponseEntity<ErrorResponse> manejarNoEncontrado(RecursoNoEncontradoException ex) {
        return construir(HttpStatus.NOT_FOUND, ex.getMessage());
    }

    @ExceptionHandler(TransicionInvalidaException.class)
    public ResponseEntity<ErrorResponse> manejarTransicionInvalida(TransicionInvalidaException ex) {
        return construir(HttpStatus.CONFLICT, ex.getMessage());
    }

    @ExceptionHandler(IaNoDisponibleException.class)
    public ResponseEntity<ErrorResponse> manejarIaNoDisponible(IaNoDisponibleException ex) {
        return construir(HttpStatus.SERVICE_UNAVAILABLE, ex.getMessage());
    }

    @ExceptionHandler(RespuestaIAInvalidaException.class)
    public ResponseEntity<ErrorResponse> manejarRespuestaIAInvalida(RespuestaIAInvalidaException ex) {
        return construir(HttpStatus.BAD_GATEWAY, ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> manejarValidacion(MethodArgumentNotValidException ex) {
        String mensaje = ex.getBindingResult().getFieldErrors().stream()
                .map(error -> error.getField() + ": " + error.getDefaultMessage())
                .sorted()
                .collect(Collectors.joining("; "));
        return construir(HttpStatus.BAD_REQUEST, mensaje);
    }

    private ResponseEntity<ErrorResponse> construir(HttpStatus status, String mensaje) {
        ErrorResponse cuerpo = new ErrorResponse(
                status.value(),
                status.getReasonPhrase(),
                mensaje,
                LocalDateTime.now()
        );
        return ResponseEntity.status(status).body(cuerpo);
    }
}
