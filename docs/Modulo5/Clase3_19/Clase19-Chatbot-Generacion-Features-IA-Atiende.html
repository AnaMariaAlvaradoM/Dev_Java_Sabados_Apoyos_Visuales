# SPEC · Atiende · Fase 3: la IA trabaja con el equipo y con el cliente

## Problema
Llegan 300 mensajes al día y el equipo tarda unos 4 minutos por ticket en leer, clasificar, buscar el pedido y redactar la respuesta: 20 horas de trabajo para 16 horas disponibles.

## Objetivo de la fase 3
1. Clasificar un ticket con IA (categoría, prioridad, sentimiento, resumen y número de pedido) y guardar el resultado.
2. Redactar un borrador de respuesta con datos verificados del pedido. Lo aprueba una persona.
3. Un chatbot para el chat web que responde preguntas frecuentes y escala a una persona cuando hace falta.

## Fuera de alcance (llega después)
- Clasificar automáticamente al crear el ticket.
- Enviar correos o mensajes de WhatsApp de verdad.
- Guardar las conversaciones del chatbot.
- Autenticación (deuda técnica declarada desde la Fase 2).

## Prompts
Viven en `src/main/resources/prompts/` como archivos `.txt`, con variables `{{nombre}}`.

| Archivo | Variables | Uso |
|---|---|---|
| sentimiento.txt | ninguna | Análisis de sentimiento (Fase 2) |
| clasificacion.txt | ninguna | Clasificación del ticket |
| borrador-respuesta.txt | cliente, formato, datos | Borrador de respuesta |
| chatbot.txt | cliente, datos | Chatbot del chat web |

## Categorías
ENVIO, PRODUCTO, PAGO, CONSULTA, OTRO.

## Reglas
1. Los prompts no se escriben dentro de clases Java.
2. El texto del cliente nunca se mezcla con las instrucciones: va siempre como mensaje aparte.
3. Toda respuesta en JSON se valida. Si no es JSON válido, le faltan campos o trae valores no permitidos: 502.
4. El número de pedido que proponga la IA solo se guarda si aparece en el mensaje del cliente.
5. Los datos del pedido (estado, transportadora, guía, fechas y días de retraso) los calcula y redacta Java. La IA solo los comunica.
6. El borrador nunca se envía solo: lo revisa una persona. Si el canal es CORREO lleva asunto; si no, no.
7. El chatbot nunca promete cupones, descuentos ni reembolsos. Si su respuesta lo hace, el cliente recibe un mensaje seguro y se escala.
8. Al escalar, el chatbot crea un ticket con canal CHAT_WEB y los mensajes del cliente.
9. El chatbot no guarda memoria: el historial llega completo en cada petición (máximo 20 turnos de 500 caracteres).

## Pedidos
Viven en el sistema de la tienda (simulado en `PedidoService`): 1045, 1046 y 1050.

# Atiende · instrucciones para el agente

## Contexto
Backend de atención al cliente de Grano Alto Café.
Antes de cambiar reglas de negocio, lee `SPEC.md`: es la fuente de verdad.

## Stack
- Java 17, Spring Boot 4.1, Maven, MySQL.
- Configuración solo en `application.properties`. Nunca `application.yml` ni perfiles.

## Arquitectura
- Paquete base `com.devsenior.atiende`, organizado por dominio: `ticket/`, `pedido/`, `chat/`, `ia/`, `compartido/`.
- Capas: Controller → Service → Repository. El Controller no tiene lógica de negocio.
- DTOs como `record` en `<dominio>/dto`. Nunca expongas entidades JPA en la API.
- Un mapper propio por dominio (`@Component`), sin librerías de mapeo.
- Inyección por constructor. Nunca `@Autowired` sobre atributos.
- Enums persistidos con `@Enumerated(EnumType.STRING)`.
- Errores con excepciones propias y un `@RestControllerAdvice` en `compartido/`.

## Código
- Clases, métodos y variables en español.
- Sin Lombok: getters y setters explícitos.
- Validación de entrada con Jakarta Validation en los DTO de request.

## Tests
- JUnit 5 + Mockito. Los tests del Service no levantan Spring.
- Nunca modifiques un test para que pase. Si un test falla, explícame si la causa está en el test o en el código y espera mi decisión.
- Un test rojo contra la SPEC es una pregunta de negocio: no la resuelvas tú.
- Si un cambio de contrato pedido en la SPEC obliga a ajustar cómo se construyen los datos de un test, puedes ajustarlo, pero nunca cambies lo que el test comprueba.

## IA
- Todo proveedor de IA implementa la interfaz `ProveedorIA` en el paquete `ia/`.
- Las llamadas HTTP se hacen con `RestClient`. Sin SDKs de proveedores ni Spring AI.
- Nunca escribas llaves en el código ni en `application.properties`: van en `secrets.properties`, que no puedes leer.
- Antes de usar una URL, un header, un parámetro o un nombre de modelo de una API de IA, verifícalo en la documentación oficial actual. Tu conocimiento puede estar desactualizado.
- Nunca registres en logs el mensaje del cliente ni las llaves.
- Los prompts viven en `src/main/resources/prompts/*.txt` y se cargan con `BibliotecaPrompts`. Nunca escribas un prompt dentro de una clase Java ni modifiques un `.txt` sin que te lo pida.
- El texto del cliente va siempre como mensaje, nunca dentro de las instrucciones.
- Toda respuesta JSON de la IA se lee con `LectorJsonIA` y se valida antes de usarla.
- Los cálculos (fechas, días, dinero) los hace Java, nunca la IA.

## Límites
- No agregues dependencias al `pom.xml` sin preguntarme.
- No modifiques `application.properties` salvo que te lo pida.
- Si algo de la SPEC es ambiguo, pregunta antes de suponer.

package com.devsenior.atiende.ia;

import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.Map;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Component;

@Component
public class BibliotecaPrompts {

    public String cargar(String nombre) {
        return cargar(nombre, Map.of());
    }

    public String cargar(String nombre, Map<String, String> variables) {
        String prompt = leerArchivo(nombre);
        for (Map.Entry<String, String> variable : variables.entrySet()) {
            prompt = prompt.replace("{{" + variable.getKey() + "}}", variable.getValue());
        }
        if (prompt.contains("{{")) {
            throw new IllegalStateException("El prompt '" + nombre + "' tiene variables sin reemplazar");
        }
        return prompt;
    }

    private String leerArchivo(String nombre) {
        ClassPathResource archivo = new ClassPathResource("prompts/" + nombre + ".txt");
        try (InputStream entrada = archivo.getInputStream()) {
            return new String(entrada.readAllBytes(), StandardCharsets.UTF_8);
        } catch (IOException ex) {
            throw new IllegalStateException("No existe el prompt '" + nombre + "'", ex);
        }
    }
}

package com.devsenior.atiende.ia;

import org.springframework.stereotype.Component;
import tools.jackson.core.JacksonException;
import tools.jackson.databind.ObjectMapper;

@Component
public class LectorJsonIA {

    private final ObjectMapper objectMapper;

    public LectorJsonIA(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }

    public <T> T leer(RespuestaIA respuesta, Class<T> tipo) {
        String texto = respuesta.texto();
        int inicio = texto.indexOf('{');
        int fin = texto.lastIndexOf('}');
        if (inicio < 0 || fin < inicio) {
            throw new RespuestaIAInvalidaException(respuesta.proveedor(), texto);
        }
        try {
            return objectMapper.readValue(texto.substring(inicio, fin + 1), tipo);
        } catch (JacksonException ex) {
            throw new RespuestaIAInvalidaException(respuesta.proveedor(), texto);
        }
    }
}

import com.devsenior.atiende.compartido.RecursoNoEncontradoException;
import com.devsenior.atiende.ticket.dto.TicketRequest;
import com.devsenior.atiende.ticket.dto.TicketResponse;
import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class TicketService {

    private final TicketRepository ticketRepository;
    private final TicketMapper ticketMapper;

    public TicketService(TicketRepository ticketRepository, TicketMapper ticketMapper) {
        this.ticketRepository = ticketRepository;
        this.ticketMapper = ticketMapper;
    }

    @Transactional
    public TicketResponse crear(TicketRequest request) {
        Ticket ticket = ticketMapper.toEntity(request);
        ticket.setEstado(EstadoTicket.ABIERTO);
        ticket.setPrioridad(Prioridad.MEDIA);
        return ticketMapper.toResponse(ticketRepository.save(ticket));
    }

    @Transactional(readOnly = true)
    public List<TicketResponse> listar(EstadoTicket estado) {
        List<Ticket> tickets = (estado == null)
                ? ticketRepository.findAllByOrderByFechaCreacionDesc()
                : ticketRepository.findByEstadoOrderByFechaCreacionDesc(estado);
        return tickets.stream()
                .map(ticketMapper::toResponse)
                .toList();
    }

    @Transactional(readOnly = true)
    public TicketResponse buscarPorId(Long id) {
        return ticketMapper.toResponse(obtenerTicket(id));
    }

    @Transactional
    public TicketResponse cambiarEstado(Long id, EstadoTicket nuevoEstado) {
        Ticket ticket = obtenerTicket(id);
        if (!ticket.getEstado().puedeCambiarA(nuevoEstado)) {
            throw new TransicionInvalidaException(ticket.getEstado(), nuevoEstado);
        }
        ticket.setEstado(nuevoEstado);
        return ticketMapper.toResponse(ticketRepository.saveAndFlush(ticket));
    }

    @Transactional
    public TicketResponse aplicarClasificacion(Long id, ClasificacionIA clasificacion, Long numeroPedido) {
        Ticket ticket = obtenerTicket(id);
        ticket.setCategoria(clasificacion.categoria());
        ticket.setPrioridad(clasificacion.prioridad());
        ticket.setSentimiento(clasificacion.sentimiento());
        ticket.setResumen(clasificacion.resumen());
        ticket.setNumeroPedido(numeroPedido);
        return ticketMapper.toResponse(ticketRepository.saveAndFlush(ticket));
    }

    private Ticket obtenerTicket(Long id) {
        return ticketRepository.findById(id)
                .orElseThrow(() -> new RecursoNoEncontradoException("No existe el ticket con id " + id));
    }
}

import com.devsenior.atiende.ia.AsistenteIA;
import com.devsenior.atiende.ia.BibliotecaPrompts;

import com.devsenior.atiende.ia.RespuestaIA;
import com.devsenior.atiende.ia.RespuestaIAInvalidaException;
import com.devsenior.atiende.ia.dto.FacturaIA;
import com.devsenior.atiende.ticket.dto.ClasificacionResponse;
import com.devsenior.atiende.ticket.dto.TicketResponse;
import java.util.regex.Pattern;
import org.springframework.stereotype.Service;

@Service
public class ClasificacionService {

    private final TicketService ticketService;
    private final AsistenteIA asistenteIA;
    private final BibliotecaPrompts bibliotecaPrompts;
    private final LectorJsonIA lectorJsonIA;

    public ClasificacionService(TicketService ticketService, AsistenteIA asistenteIA,
                                BibliotecaPrompts bibliotecaPrompts, LectorJsonIA lectorJsonIA) {
        this.ticketService = ticketService;
        this.asistenteIA = asistenteIA;
        this.bibliotecaPrompts = bibliotecaPrompts;
        this.lectorJsonIA = lectorJsonIA;
    }

    public ClasificacionResponse clasificar(Long ticketId) {
        TicketResponse ticket = ticketService.buscarPorId(ticketId);
        String instrucciones = bibliotecaPrompts.cargar("clasificacion");
        RespuestaIA respuesta = asistenteIA.completar(instrucciones, ticket.mensaje());

        ClasificacionIA clasificacion = lectorJsonIA.leer(respuesta, ClasificacionIA.class);
        if (!clasificacion.estaCompleta()) {
            throw new RespuestaIAInvalidaException(respuesta.proveedor(), respuesta.texto());
        }
        Long numeroPedido = apareceEnElMensaje(clasificacion.numeroPedido(), ticket.mensaje())
                ? clasificacion.numeroPedido()
                : null;

        TicketResponse clasificado = ticketService.aplicarClasificacion(ticketId, clasificacion, numeroPedido);
        return new ClasificacionResponse(clasificado, FacturaIA.de(respuesta));
    }

    private boolean apareceEnElMensaje(Long numeroPedido, String mensaje) {
        return numeroPedido != null
                && Pattern.compile("\\b" + numeroPedido + "\\b").matcher(mensaje).find();
    }

    private final Map<Long, Pedido> pedidos;

    public PedidoService() {
        LocalDate hoy = LocalDate.now();
        this.pedidos = Map.of(
                1045L, new Pedido(1045L, "Café de Huila 500 g", EstadoPedido.ENVIADO,
                        "TransAndina", "TA-778201", hoy.minusDays(3)),
                1046L, new Pedido(1046L, "Café de Nariño 250 g", EstadoPedido.EN_PREPARACION,
                        null, null, hoy.plusDays(4)),
                1050L, new Pedido(1050L, "Café de Tolima 500 g", EstadoPedido.ENTREGADO,
                        "TransAndina", "TA-779940", hoy.minusDays(6)));
    }

    public Optional<Pedido> buscar(Long numero) {
        return Optional.ofNullable(pedidos.get(numero));
    }

    public String datosVerificados(Long numero) {
        if (numero == null) {
            return "- El cliente no ha dado un número de pedido.";
        }
        return buscar(numero)
                .map(this::describir)
                .orElse("- No existe un pedido con el número " + numero + ".");
    }

    private String describir(Pedido pedido) {
        String producto = "- El pedido " + pedido.numero() + " (" + pedido.producto() + ")";
        String fecha = pedido.entregaEstimada().format(FORMATO_FECHA);
        return switch (pedido.estado()) {
            case EN_PREPARACION -> producto + " está en preparación y todavía no ha salido.\n"
                    + "- La entrega está estimada para el " + fecha + ".";
            case ENVIADO -> producto + " fue enviado con " + pedido.transportadora()
                    + ", guía " + pedido.numeroGuia() + ".\n" + describirEntrega(pedido, fecha);
            case ENTREGADO -> producto + " ya fue entregado.";
        };
    }

    private String describirEntrega(Pedido pedido, String fecha) {
        long diasDeRetraso = ChronoUnit.DAYS.between(pedido.entregaEstimada(), LocalDate.now());
        if (diasDeRetraso > 0) {
            return "- La entrega estaba estimada para el " + fecha + ": lleva "
                    + diasDeRetraso + " días de retraso.";
        }
        return "- La entrega está estimada para el " + fecha + ".";
    }

@Service
public class ChatbotService {

    record RespuestaChatbotIA(String respuesta, boolean escalar) {
    }

    private static final int MAXIMO_MENSAJE_TICKET = 2000;

    private final PedidoService pedidoService;
    private final TicketService ticketService;
    private final AsistenteIA asistenteIA;
    private final BibliotecaPrompts bibliotecaPrompts;
    private final LectorJsonIA lectorJsonIA;

    public ChatbotService(PedidoService pedidoService, TicketService ticketService,
                          AsistenteIA asistenteIA, BibliotecaPrompts bibliotecaPrompts,
                          LectorJsonIA lectorJsonIA) {
        this.pedidoService = pedidoService;
        this.ticketService = ticketService;
        this.asistenteIA = asistenteIA;
        this.bibliotecaPrompts = bibliotecaPrompts;
        this.lectorJsonIA = lectorJsonIA;
    }

    public ChatResponse responder(ChatRequest request) {
        String instrucciones = bibliotecaPrompts.cargar("chatbot", Map.of(
                "cliente", request.clienteNombre(),
                "datos", pedidoService.datosVerificados(request.numeroPedido())));
        RespuestaIA respuesta = asistenteIA.completar(instrucciones, comoConversacion(request.historial()));

        RespuestaChatbotIA chatbot = lectorJsonIA.leer(respuesta, RespuestaChatbotIA.class);
        if (chatbot.respuesta() == null || chatbot.respuesta().isBlank()) {
            throw new RespuestaIAInvalidaException(respuesta.proveedor(), respuesta.texto());
        }

        Long ticketId = chatbot.escalar() ? escalarATicket(request) : null;
        return new ChatResponse(chatbot.respuesta(), chatbot.escalar(), ticketId, FacturaIA.de(respuesta));
    }

    private String comoConversacion(List<ChatRequest.Turno> historial) {
        return historial.stream()
                .map(turno -> (turno.rol() == ChatRequest.Rol.CLIENTE ? "Cliente: " : "Grano: ") + turno.texto())
                .collect(Collectors.joining("\n"));
    }

    private Long escalarATicket(ChatRequest request) {

                .map(ChatRequest.Turno::texto)
                .collect(Collectors.joining(" | "));
        if (mensajesDelCliente.length() > MAXIMO_MENSAJE_TICKET) {
            mensajesDelCliente = mensajesDelCliente.substring(0, MAXIMO_MENSAJE_TICKET);
        }
        TicketResponse ticket = ticketService.crear(new TicketRequest(
                request.clienteNombre(), request.clienteContacto(), Canal.CHAT_WEB, mensajesDelCliente));
        return ticket.id();
    }

import java.util.List;
import java.util.Locale;

import java.util.stream.Collectors;
import org.springframework.stereotype.Service;

@Service
public class ChatbotService {

    record RespuestaChatbotIA(String respuesta, boolean escalar) {
    }

    private static final int MAXIMO_MENSAJE_TICKET = 2000;
    private static final List<String> PROMESAS_PROHIBIDAS = List.of("cupón", "cupon", "descuento", "reembols");
    private static final String RESPUESTA_SEGURA =
            "Una persona de nuestro equipo revisará su solicitud y lo contactará pronto.";

    private final PedidoService pedidoService;
    private final TicketService ticketService;
    private final AsistenteIA asistenteIA;
    private final BibliotecaPrompts bibliotecaPrompts;
    private final LectorJsonIA lectorJsonIA;

    public ChatbotService(PedidoService pedidoService, TicketService ticketService,
                          AsistenteIA asistenteIA, BibliotecaPrompts bibliotecaPrompts,
                          LectorJsonIA lectorJsonIA) {
        this.pedidoService = pedidoService;
        this.ticketService = ticketService;
        this.asistenteIA = asistenteIA;
        this.bibliotecaPrompts = bibliotecaPrompts;
        this.lectorJsonIA = lectorJsonIA;
    }

    public ChatResponse responder(ChatRequest request) {
        String instrucciones = bibliotecaPrompts.cargar("chatbot", Map.of(
                "cliente", request.clienteNombre(),
                "datos", pedidoService.datosVerificados(request.numeroPedido())));
        RespuestaIA respuesta = asistenteIA.completar(instrucciones, comoConversacion(request.historial()));

        RespuestaChatbotIA chatbot = lectorJsonIA.leer(respuesta, RespuestaChatbotIA.class);
        if (chatbot.respuesta() == null || chatbot.respuesta().isBlank()) {
            throw new RespuestaIAInvalidaException(respuesta.proveedor(), respuesta.texto());
        }

        if (prometeAlgoNoPermitido(chatbot.respuesta())) {
            return new ChatResponse(RESPUESTA_SEGURA, true, escalarATicket(request), FacturaIA.de(respuesta));
        }
        Long ticketId = chatbot.escalar() ? escalarATicket(request) : null;
        return new ChatResponse(chatbot.respuesta(), chatbot.escalar(), ticketId, FacturaIA.de(respuesta));
    }

    private boolean prometeAlgoNoPermitido(String respuesta) {
        String texto = respuesta.toLowerCase(Locale.ROOT);
        return PROMESAS_PROHIBIDAS.stream().anyMatch(texto::contains);
    }

    private String comoConversacion(List<ChatRequest.Turno> historial) {
        return historial.stream()
                .map(turno -> (turno.rol() == ChatRequest.Rol.CLIENTE ? "Cliente: " : "Grano: ") + turno.texto())
                .collect(Collectors.joining("\n"));
    }

    private Long escalarATicket(ChatRequest request) {
        String mensajesDelCliente = request.historial().stream()
                .filter(turno -> turno.rol() == ChatRequest.Rol.CLIENTE)
                .map(ChatRequest.Turno::texto)
                .collect(Collectors.joining(" | "));
        if (mensajesDelCliente.length() > MAXIMO_MENSAJE_TICKET) {
            mensajesDelCliente = mensajesDelCliente.substring(0, MAXIMO_MENSAJE_TICKET);
        }
        TicketResponse ticket = ticketService.crear(new TicketRequest(
                request.clienteNombre(), request.clienteContacto(), Canal.CHAT_WEB, mensajesDelCliente));
        return ticket.id();
    }
}

Atiende ya trabaja; ahora falta dispararlo solo

La fila se ordena, los borradores parten de hechos y el chat resuelve o escala bajo límites explícitos.

  1. El prompt es código: vive en archivos, se versiona y mantiene el mensaje del cliente separado.
